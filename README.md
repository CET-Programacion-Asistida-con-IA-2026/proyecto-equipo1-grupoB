# Voluntarios para Comedores Comunitarios

## Descripción del Proyecto

Este proyecto consiste en una aplicación web destinada a conectar personas interesadas en realizar voluntariados o colaborar con comedores comunitarios de la Ciudad Autónoma de Buenos Aires.

La plataforma busca facilitar el acceso a información sobre los comedores, permitiendo conocer su ubicación, las necesidades actuales de cada institución y las formas de colaborar.

---

## Problema

Muchas personas desean participar en acciones solidarias o realizar voluntariados en comedores comunitarios, pero desconocen dónde se encuentran estos lugares y qué tipo de ayuda necesitan.

Esta falta de información dificulta la conexión entre quienes quieren colaborar y las organizaciones que requieren apoyo.

### Ubicación

Ciudad Autónoma de Buenos Aires, Argentina.

---

## Público Objetivo

La aplicación está dirigida a:

* Personas mayores de 16 años. (pues es la edad mínima para realizar voluntariados)
* Ciudadanos interesados en realizar voluntariados.
* Personas que deseen realizar donaciones a comedores comunitarios.
* Organizaciones que necesiten visibilizar sus necesidades y actividades.

---

## Solución Propuesta

Desarrollar una aplicación web que permita acceder fácilmente a información sobre comedores comunitarios, mostrando su ubicación y las necesidades específicas de cada uno.

El objetivo es generar un puente entre los voluntarios y las organizaciones, facilitando la colaboración y aumentando el alcance de las acciones solidarias. De esta menra se contribuye con los objetivos de desarrollo sostenible de la ONU 2 y 3 correspondientes a hambre cero y salud bienestar respectivamente.

---

## Funcionalidades Principales

### 📍 Mapa de Comedores

Visualización de un mapa interactivo con la ubicación de los comedores que buscan voluntarios o reciben donaciones.

### 📝 Registro de Voluntarios

Formulario que permita a los usuarios inscribirse como voluntarios y ponerse en contacto con los comedores.


---

## Tecnologías

Para el desarrollo de este proyecto vamos a usar los lenguajes:

* JavaScript
* HTML
* CSS

---

## Objetivo General

Facilitar la participación ciudadana en actividades solidarias mediante una plataforma accesible que conecte voluntarios y donantes con comedores comunitarios.
